# Озвучка

Android-приложение для чтения и локальной озвучки книг. Основной сценарий: выбрать файл или отправить ссылку на главу из браузера, читать в приложении, затем при желании сохранить нормализованный текст как EPUB или FB2.

## Сейчас реализовано

- Импорт EPUB, FB2/FB2.ZIP, PDF, DOCX, TXT, HTML и Markdown.
- PDF: извлечение текста с сохранением порядка по координатам; для страниц без текста — локальное OCR Tesseract с русским и английским языками. Во время длинного импорта отображается ход работы.
- Библиотека с поиском, фильтрами, сохранением позиции и удалением книги после подтверждения.
- Читалка с анимированным перелистыванием жестами вправо и влево, размером и семейством шрифта, светлой, тёмной и сепия темами, навигацией по главам. Касание страницы показывает или скрывает панели управления; кнопка «Скрыть» переводит чтение в полноэкранный режим без системных строк.
- Экспорт нормализованной книги в EPUB 3 и FB2.
- Добавление одной веб-главы по URL или через Android «Поделиться»; следующая глава загружается только по нажатию пользователя.
- Нейроозвучка Supertonic 3 через sherpa-onnx: 10 голосов с прослушиванием примера. Базовая модель INT8 загружается один раз; доступны также полноточные веса. Во время воспроизведения читалка подсвечивает текущую фразу и автоматически перелистывает страницы. После загрузки синтез работает на устройстве без сети. Полноточный вариант занимает больше памяти и может озвучивать медленнее.

## Качество голоса

В основной читалке пока работает Supertonic 3. Отдельное исследовательское приложение Qwen3-TTS 0.6B даёт пользователю более приятный русский голос, но на Galaxy S24 Ultra пробная CPU-генерация 8,64 секунды звука заняла около восьми минут. На короткой одинаковой фразе Q4_K_M создал 1,60 секунды речи за 98 секунд, Q8_0 — 1,28 секунды за 124 секунды. [Образец Q4](docs/samples/qwen-q4-short.wav) и [образец Q8](docs/samples/qwen-q8-short.wav) сохранены для прослушивания. Ограниченный OpenCL-запуск Q8 завершился сбоем в `ggml-opencl` до сохранения WAV, поэтому этот движок пока нельзя использовать для непрерывной озвучки. Подробности: [исследование Qwen](docs/QWEN_GPU_POC.md), [воспроизведение эксперимента](docs/QWEN_RESEARCH.md) и [кандидаты голосов](docs/VOICE_CANDIDATES.md).

## Ограничения преобразования

PDF не хранит однозначный порядок чтения и разметку глав. Для сложных колонок, таблиц, сносок и плохих сканов проверьте текст в читалке перед экспортом. OCR может ошибаться. Текущая текстовая читалка не сохраняет иллюстрации и сложную верстку EPUB/FB2/DOCX. DRM-файлы не поддерживаются. Исходные файлы не меняются: приложение хранит свою текстовую копию в приватном каталоге.

## Сборка

Откройте папку проекта в Android Studio с JDK 17 и Android SDK 36. Сборка из командной строки: `gradlew.bat :app:assembleDebug`. APK появляется в `app/build/outputs/apk/debug/app-debug.apk`. Целевое устройство — Galaxy S24 Ultra; текущая сборка включает arm64-вариант локального движка.

При импорте русских сканов приложение использует языковые данные [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast). Базовый нейроголос скачивается из [официального релиза sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases), полноточные веса — из [репозитория Supertonic 3](https://huggingface.co/Supertone/supertonic-3/tree/main/onnx). Условия использования весов указаны в [карточке модели](https://huggingface.co/Supertone/supertonic-3). Модели не входят в APK.
